# P0: Preflight

| | |
|---|---|
| Slot | 1 |
| Needs a human | no |
| Expected run time | 3 min (timeout 10 min) |
| Requires | nothing |
| Run by | `run_slot.sh` (slot 1), or by hand with `run_gate.sh` |

## Purpose

Reports the state of the Mac before the other gates run. It checks the chip, macOS, Rosetta 2, Xcode Command Line Tools, free disk, the job dir, network reach to GitHub and Unity, Mac Steam, screen capture, the display and stray Wine processes. It only detects and reports. It never installs anything and never changes Steam.

## Preconditions

- A Mac. The gate checks this at start.
- The kit is set up at `$JOB/kit` (see `slot1.job.json`, "setup").
- `$JOB/tmp` exists. The script tests that it can write a file there.
- Network access for the GitHub and Unity checks.

## Command

```sh
cd "$JOB/kit"
bash testkit/run_gate.sh P0 --job-dir "$JOB"
```

No arguments.

## What the script does

1. Starts the gate and checks that it runs on a Mac.
2. Reads the macOS version and build, CPU type, Mac model, CPU name, memory in GB and the user name. Saves them as versions and metrics. Writes `system.txt` with `sw_vers`, `uname -a` and `sysctl` output.
3. Checks that the chip is `arm64` (criterion `arch`) and that the macOS major version is 12 or newer (`macos`).
4. Checks Rosetta 2 with `arch -x86_64` (`rosetta`). It does not install Rosetta.
5. Looks for the Xcode Command Line Tools (`clt`, info only). If found, records their version. Records the python3 path, or `none`.
6. Reads free disk space in `$HOME`, in GB (`disk`).
7. Writes and removes a test file in `$JOB/tmp` (`jobdir`).
8. Sends HEAD requests to `github.com`, `objects.githubusercontent.com` and `download.unity3d.com`, with a 15 second connect timeout. Records each HTTP code as a metric. Checks `github.com` (`net_github`) and `download.unity3d.com` (`net_unity`).
9. Checks Mac Steam, read only:
   - `Steam.app` in `/Applications` or `~/Applications` (`steam_app`, info). Records its version.
   - `steamclient.dylib` in the Steam client folder (`steam_boot`, info).
   - The Steam client version, if readable.
   - Whether `steam_osx` runs (metric only).
   - The login state, best effort (`steam_login`, info).
10. Only with `PP_SCREENSHOTS=1`: takes one screenshot with `screencapture -x` into the P0 evidence folder (`screencapture`). By default this is skipped and recorded as info, so the macOS Screen Recording prompt never appears.
11. Saves `system_profiler SPDisplaysDataType` to `displays.txt`. Records the resolution and chipset as metrics.
12. Checks that these base tools exist (`tools`): curl, shasum, tar, awk, sed, grep, pgrep, pkill, plutil, pkgutil, codesign, screencapture, memory_pressure, vm_stat, sysctl, caffeinate, defaults, file, od, dd. Writes `tar --version` to `tar-version.txt`.
13. Looks for running Wine or PEAK processes (`stray_wine`). Saves them to `wine-processes.txt` if any. It leaves them alone.
14. Notes any existing PEAK depot folder (`app_3527290`) in the Steam data folders. It only notes them. Copies the pre-existing snapshot (`$PRE_TSV`) into the log folder.
15. Sets the verdict (see Pass / fail criteria).

## Computer-use steps

None. In-kit screenshots are off unless `PP_SCREENSHOTS=1`.

## Pass / fail criteria

| Criterion id | Check | Pass when |
|---|---|---|
| `arch` | Chip is Apple Silicon | `uname -m` is arm64. Fail otherwise. |
| `macos` | macOS version | 12 or newer. Warn otherwise. |
| `rosetta` | Rosetta 2 installed | `arch -x86_64` works. Fail otherwise. |
| `clt` | Xcode Command Line Tools | Info only. Reports present or absent. |
| `disk` | Free disk in `$HOME` | 20 GB or more. Warn at 12 to 19 GB. Fail below 12 GB. |
| `jobdir` | Job dir writable | A test file can be written and removed in `$JOB/tmp`. Fail otherwise. |
| `net_github` | github.com reachable | HTTP 2xx or 3xx. Fail otherwise. |
| `net_unity` | download.unity3d.com reachable | HTTP 2xx, 3xx or 403 (info). Warn otherwise. |
| `steam_app` | Steam.app installed | Info. Reports the path, or that it was not found. |
| `steam_boot` | Steam client bootstrapped | Info. Reports whether `steamclient.dylib` exists. |
| `steam_login` | Mac Steam logged in | Info. Reports the best-effort login state. |
| `screencapture` | `screencapture -x` works (only with `PP_SCREENSHOTS=1`) | A non-empty PNG is written. Warn otherwise. Info (`off`) by default. |
| `tools` | Base tools present | Every tool in step 12 exists. Fail otherwise. |
| `stray_wine` | No Wine or PEAK processes before the job | None are running. Warn if some are. |

Status: fail when `arch`, `jobdir` or `tools` fails. Blocked (exit 2) when `rosetta`, `disk` or `net_github` fails. Otherwise pass. Warnings and info never change the status.

## Results and evidence

- `results/P0.json`: status, exit code, criteria, metrics, versions and notes.
- Versions: `macos`, `macos_build`, `arch`, `model`, `cpu`, `memory_gb`. Also `clt` (if found), `steam_app_version` (if found) and `steam_client` (if found).
- Metrics: `macos`, `macos_build`, `arch`, `model`, `cpu`, `memory_gb`, `user`, `rosetta`, `clt`, `python3`, `free_disk_gb`, `job_dir`, `http_github_com`, `http_objects_githubusercontent_com`, `http_download_unity3d_com`, `steam_app`, `steam_bootstrapped`, `steam_client_version`, `steam_running`, `steam_logged_in`, `steam_login_evidence`, `screencapture`, `display`, `gpu`.
- Logs in `logs/P0/`: `console.log`, `system.txt`, `displays.txt`, `tar-version.txt`, `preexisting.tsv`, and `wine-processes.txt` only if Wine processes are found.
- Evidence in `evidence/P0/`: `p0-screen.png`.

## Copy back

- `results/P0.json`
- `logs/P0/`
- `evidence/P0/p0-screen.png`

## Paths outside the job dir

Reads only. Writes stay in the job dir.

- `/Applications/Steam.app` and `~/Applications/Steam.app`: existence and version.
- The Mac Steam client folder: `steamclient.dylib`, and the login check (same as H-STEAM).
- Steam data folders under `~/Library/Application Support/Steam/`: checks for `steamapps/content/app_3527290`.
- The running process list (`pgrep`, for Wine and PEAK).
- Network: HEAD requests only.

## If it fails or is blocked

- `arch` fails: the host is not Apple Silicon. The gate fails. Check the machine before running other gates.
- `jobdir` fails: `$JOB/tmp` is missing or not writable. The gate fails.
- `tools` fails: the criterion detail lists the missing commands. The gate fails.
- `rosetta` fails: the gate is blocked. The script message says the hub or Joshua installs Rosetta with `softwareupdate --install-rosetta`. This kit never installs it.
- `disk` fails (below 12 GB): the gate is blocked. Free space. Slot 1 needs about 8 GB, and G-C0 needs another 6 GB (script message).
- `disk` warns (12 to 19 GB): not blocked. Slot 1 can still run.
- `net_github` fails: the gate is blocked. Check the network and re-run P0.
- `net_unity` warns: only G-C0 needs it. Slot 1 is not blocked.
- `clt` is absent: info only. G-B0 uses its fallback. G-B1 needs a prebuilt probe in the Steam test kit or the CLT.
- `screencapture` warns: gates fall back to the hub's own computer-use screenshots. If `p0-screen.png` shows only the wallpaper, the screen-recording grant is missing. The hub's tooling holds that grant; check it there.
- `stray_wine` warns: other Wine or PEAK processes are running. The kit does not stop them. See `logs/P0/wine-processes.txt`.
- `steam_app` missing: P0 does not block on it. H-STEAM is blocked by it.
