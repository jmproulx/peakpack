PeakPack for Mac: Steam bridge glue (runtime/steam)

Covers the files written by the PeakPack project in mac/runtime/steam/: the build
scripts, our lsteamclient patches (patches/*.patch), the steamclient64.dll
forwarder, peakpack_steam_launcher.exe, the test probes and the test scripts.
It does NOT cover Valve's lsteamclient sources or the lsteamclient.dll /
lsteamclient.so built from them (Steamworks SDK licence, see
lsteamclient-Steamworks-SDK-LICENSE.txt and NOTICE-steam-bridge.md).
